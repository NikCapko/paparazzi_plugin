# Paparazzi IntelliJ Plugin

Плагин для IntelliJ IDEA, который упрощает работу с [Paparazzi](https://github.com/cashapp/paparazzi) — инструментом для
snapshot-тестирования UI-компонентов Android от Cash App.

Управляйте snapshot-тестами прямо из IDE: просматривайте эталонные изображения, сравнивайте с актуальными снапшотами,
запускайте тесты точечно и перезаписывайте эталоны — без необходимости переключаться в терминал.

## ✨ Возможности

### 📋 Управление тестами

- **Автоматическая индексация** — плагин находит все Paparazzi-тесты в проекте при открытии
- **Древовидное представление** — тесты сгруппированы по модулям и классам
- **Счётчики** — на уровне модуля видно общее количество тестов и количество упавших
- **Поиск** — мгновенный поиск по имени метода или класса
- **Фильтрация** — кнопка "Failed Only" показывает только упавшие тесты

### 🚀 Запуск тестов

- **Точечный запуск** — запускайте только выбранные тесты через `--tests`
- **Запуск всех тестов** — одной кнопкой запускайте все snapshot-тесты в проекте
- **Re-record** — перезаписывайте эталонные снимки для выбранных тестов или всех упавших
- **Прогресс-бар** — визуальная индикация процесса индексации и выполнения тестов

### 🖼️ Просмотр изображений

- **Reference snapshots** — просмотр эталонных изображений прямо в IDE
- **Failure diffs** — сравнение с актуальными снимками при падении теста
- **Масштабирование** — зум колесиком мыши с зажатой клавишей Ctrl
- **Параметризованные тесты** — корректная группировка снапшотов для тестов с параметрами

### 🎯 Навигация и удобство

- **Двойной клик** — переход к исходному коду теста
- **Контекстное меню** — быстрые действия по правому клику:
    - Run Test
    - Re-record Snapshot
    - Open Source
    - Open Reference Snapshot
    - Open Failure Diff
    - Copy Gradle Command
    - Copy Test FQN
- **Копирование команд** — мгновенное копирование Gradle-команды для запуска теста

## 🔧 Требования

- **IntelliJ IDEA** 2025.3 или новее (или Android Studio на базе этой версии)
- **Kotlin** плагин (встроен или установлен)
- **Java** плагин (встроен или установлен)
- Проект с подключённым [Paparazzi](https://github.com/cashapp/paparazzi)
- Gradle-сборка (Kotlin DSL или Groovy DSL)

## 📦 Установка

### Из архива (рекомендуется)

1. Скачайте последнюю версию плагина из [Releases](https://github.com/NikCapko/paparazzi_plugin/releases)
2. Откройте IntelliJ IDEA → `Settings/Preferences` → `Plugins`
3. Нажмите ⚙️ → `Install Plugin from Disk...`
4. Выберите скачанный `.zip` файл
5. Перезапустите IDE

### Сборка из исходников

```bash
git clone https://github.com/NikCapko/paparazzi_plugin.git
cd paparazzi_plugin
./gradlew buildPlugin
```

Собранный плагин будет находиться в `build/distributions/`

## 🚀 Использование

### Первый запуск

1. Откройте проект с Paparazzi-тестами
2. Плагин автоматически проиндексирует все тесты (прогресс-бар в правом нижнем углу)
3. Откройте панель **Paparazzi** (обычно внизу экрана)

### Запуск тестов

#### Запустить выбранный тест
1. Выберите тест в дереве
2. Нажмите кнопку **Run Selected Test** (▶️) в toolbar или правый клик → `Run Test`

#### Запустить все тесты
Нажмите кнопку **Run All Paparazzi Tests** (▶️▶️) в toolbar

#### Перезаписать эталоны
1. Выберите тесты (или все упавшие через фильтр)
2. Нажмите **Re-record Snapshots** (🔄) в toolbar или правый клик → `Re-record Snapshot`

### Просмотр изображений

1. Выберите тест в дереве
2. Во вкладке **Reference** увидите эталонные изображения
3. Если тест упал, во вкладке **Delta** увидите diff

### Масштабирование
- **Ctrl + колесико мыши** — зум изображений
- **Слайдер** — ручная настройка масштаба (25% - 100%)

## ⚙️ Настройки

Откройте `Settings/Preferences` → `Tools` → `Paparazzi`

### Доступные настройки

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| **Task suffix** | Суффикс для Gradle-тасков (например, `Debug`, `GmsDebug`, `FirebaseDebug`) | `Debug` |

**Пример:** Если суффикс `Debug`, плагин будет запускать:
- `:module:verifyPaparazziDebug`
- `:module:recordPaparazziDebug`

## ⌨️ Горячие клавиши

| Действие | Горячая клавиша |
|----------|-----------------|
| Перейти к исходному коду теста | Двойной клик по тесту в дереве |
| Масштабирование изображений | Ctrl + колесико мыши |

## 🐛 Известные ограничения

1. **Только Kotlin** — индексация работает только для Kotlin-файлов (`.kt`). Java-тесты не поддерживаются.
2. **Базовый класс** — плагин ищет классы, наследующиеся от `PaparazziBaseTest`, `BaseScreenshotTest`, `ScreenshotTest`. Если у вас другой базовый класс, тесты не будут найдены.
3. **Параметризованные тесты** — поддержка ограничена. Имя метода в XML-отчёте должно начинаться с имени теста (например, `testMethod[0]`).
4. **Gradle sync** — плагин не отслеживает изменения в `build.gradle.kts`. После изменения конфигурации Gradle может потребоваться ручной refresh.
5. **Один вариант сборки** — плагин использует один суффикс для всех модулей. Если в проекте разные варианты сборки для разных модулей, настройте самый используемый.

## 🛠 Разработка

### Сборка плагина

```bash
./gradlew buildPlugin
```

### Запуск тестового экземпляра IDE

```bash
./gradlew runIde
```

Это запустит отдельный экземпляр IntelliJ IDEA с установленным плагином для тестирования.

### Структура проекта

```
src/main/
├── kotlin/com/nikcapko/paparazzi/
│   ├── PaparazziIndexer.kt          # Индексация тестов
│   ├── PaparazziTestRegistry.kt     # Хранение состояния тестов
│   ├── PaparazziGradleRunner.kt     # Запуск Gradle-тасков
│   ├── PaparazziToolWindowFactory.kt # UI панели
│   ├── PaparazziActions.kt          # Действия toolbar
│   ├── PaparazziContextMenuActions.kt # Действия контекстного меню
│   ├── PaparazziSettings.kt         # Настройки плагина
│   └── PaparazziConfigurable.kt     # UI настроек
└── resources/META-INF/
    └── plugin.xml                   # Конфигурация плагина
```
